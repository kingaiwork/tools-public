# Changelog / 更新日志

This changelog covers public-facing KING AI Online Tools changes only. It intentionally excludes private implementation and deployment details.

本更新日志仅记录 KING AI 在线工具面向用户的公开变化，不包含私有实现和部署细节。

- Search-demand-based popular tool presentation.

- Reduced oversized homepage typography.

### Architecture / 架构
- Public website and public documentation are separated from private production source code.
- Production source, credentials and sensitive deployment information remain private.
