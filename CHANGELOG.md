# Changelog / 更新日志

This changelog covers public-facing KING AI Online Tools changes only. It intentionally excludes private implementation and deployment details.

本更新日志仅记录 KING AI 在线工具面向用户的公开变化，不包含私有实现和部署细节。

## 2026-08-12

### Added / 新增
- Public project repository for documentation and product transparency.
- Search-demand-based popular tool presentation.
- English and Simplified Chinese public experience.
- Bookmark, homepage guidance and share actions.
- Adaptive weekday and selected seasonal/holiday visual themes.
- Expanded machine-readable SEO/GEO information.
- Dedicated responsive layout correction layer for consistent desktop, tablet and mobile presentation.

### Improved / 优化
- Reduced oversized homepage typography and tightened hero height.
- Corrected the second headline scale so it no longer dominates the viewport.
- Improved desktop wide-screen balance and maximum content width.
- Rebuilt popular-tool presentation into a consistent responsive card grid.
- Unified button sizes and separated primary actions from bookmark/home/share utilities.
- Improved mobile spacing, cards, visual hierarchy and contrast.
- Surfaced high-demand calculators, converters, word counter and time tools earlier.
- Improved titles, descriptions, structured data, FAQs and internal topic clarity.

### Architecture / 架构
- Production source repository is private.
- Public documentation/showcase repository is public.
- Public website delivery is separated from source-code visibility.
- Production source, credentials, private deployment details, database structures and proprietary business logic remain private.
