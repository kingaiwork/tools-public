# Security & Disclosure / 安全与披露

## Public repository boundary

This repository is documentation-only and must not contain production secrets or sensitive implementation details.

Do not publish:

- API keys, tokens, passwords or certificates
- Private repository content
- Production deployment credentials
- Database schemas containing internal structure
- Private endpoints or service-discovery data
- Internal business logic
- Security-control implementation details that could weaken protection
- Customer/private user data

## Reporting a security concern

For security-related concerns involving KING AI Online Tools, contact:

vip@kingai.work

Please avoid publishing sensitive vulnerability details publicly before there is a reasonable opportunity to review and address the issue.
