# Roadmap / 路线图

This roadmap describes public product directions, not internal commitments or confidential implementation plans.

## Near term

- Continue expanding high-value browser tools based on verified user/search demand.
- Improve tool discovery and ranking without hiding the full catalog.
- Strengthen English and Simplified Chinese coverage.
- Improve mobile usability, accessibility and performance.
- Expand public SEO/GEO documentation and machine-readable facts.
- Add screenshots and product demos to this public repository.

## Planned exploration

- More browser-side image and document utilities where privacy-friendly implementation is practical.
- QR code utilities and other high-demand tools after security/privacy review.
- Better favorites/recent-tools experience.
- More localization where there is clear user demand.
- Public integration/API capabilities only when intentionally approved for external use.

## Long-term direction

- Keep the public utility experience simple and fast.
- Connect useful tools naturally with the broader KING AI ecosystem.
- Maintain a clear boundary between public documentation and private production implementation.

# 中文路线图

近期重点包括：继续根据真实需求扩展高价值工具、优化热门排序与搜索、提升中英文内容、改善手机端和可访问性、增强 SEO/GEO 与机器可读信息，并逐步补充公开截图和演示。

未来会评估更多浏览器端图片/文档工具、二维码工具、收藏与最近使用能力、多语言，以及经过明确批准的公共接口能力。

长期原则是：公共工具保持简单、快速、实用，同时与 KING AI 生态自然连接，并始终保持“公开文档”和“私有生产实现”的边界。
