# Usage Guide / 使用说明

## Open the site

Visit: https://tools.kingai.work

Use the language switch to move between English and Simplified Chinese.

## Find a tool

You can:

1. Start from the Popular Tools section.
2. Search by tool name or task.
3. Filter by category.
4. Open a tool and complete the task directly on the page.

## Privacy note

Many tools perform calculations, text transformations or image operations directly in your browser. However, do not assume every future tool has identical behavior. Avoid entering highly sensitive data unless you understand how the specific tool processes information.

## Results disclaimer

Financial, health, tax and other calculated results are informational estimates only and do not constitute professional advice.

# 中文使用说明

访问：https://tools.kingai.work

你可以从“热门工具”直接进入常用功能，也可以使用搜索框或分类筛选查找完整工具库。打开工具后即可在当前页面完成计算或处理。

大量计算、文本转换和图片操作直接在浏览器中完成，但不同工具未来可能采用不同实现。处理高度敏感信息前，请先确认具体工具的处理方式。

金融、健康、税务及其他计算结果仅供参考，不构成专业建议。
