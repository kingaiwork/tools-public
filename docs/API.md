# Public API / Interface Notes

KING AI Online Tools is currently presented primarily as a browser-based public utility website.

## Current public interface

Website: https://tools.kingai.work

No private production API credentials, internal service endpoints, database interfaces or privileged automation interfaces are documented in this repository.

If selected public APIs are introduced in the future, this document may publish only the intentionally public parts, such as:

- Public endpoint purpose
- Request/response examples using non-sensitive sample data
- Authentication requirements for public clients, if any
- Published rate limits
- Versioning policy
- Error format
- Deprecation policy

## Security boundary

Never place API keys, secrets, internal endpoints, private schemas or production credentials in this public repository.
